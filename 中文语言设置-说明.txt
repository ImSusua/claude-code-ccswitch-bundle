Claude Code 中文语言设置工具（独立版，v1.0.0）
================================================

【用途】
给已经安装了 Claude Code 的用户一键设置回复语言（默认简体中文）。
不依赖任何安装包，不联网，不需要管理员权限。
对 npm 安装、官方原生安装、离线合并安装包安装的 Claude Code 均适用。

【使用方法】
双击「中文设置.cmd」，按菜单选择即可：
  [1] 简体中文（推荐）
  [2] 繁體中文
  [3] English
  [4] 自定义（任意语言描述）
  [0] 退出

【进阶用法】（在 cmd/PowerShell 中）
  中文设置.cmd 简体中文            直接设置为指定语言
  中文设置.cmd -Show              仅查看当前设置
  中文设置.cmd -Remove            还原：移除语言设置与规则块
  （脚本本体为同目录 set-language.ps1）

【它改了什么】
1. ~/.claude/settings.json   合并写入官方 "language" 键（保留你的其他配置，如 API 供应商）
2. ~/.claude/CLAUDE.md       维护一个带标记的语言规则块（重复运行不会重复追加）

【生效方式】
新开的 claude 会话即生效；正在运行的会话请退出后重新进入。

【说明】
- 该设置控制 AI 的回复语言（回复、会话标题等）；
  Claude Code 终端界面（菜单/面板）官方目前没有简体中文版，属官方现状。
- 卸载/还原：运行「中文设置.cmd -Remove」，或手动删除 settings.json 里的 language 键。

设置后 claude 无法使用、报 403？
  那是还没有配置 API 供应商（与语言无关）：请用 CC Switch 等工具配置
  供应商（Base URL + API Key），重开终端再运行 claude。
